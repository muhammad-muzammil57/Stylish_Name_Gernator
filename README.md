# 🌟 Stylish Name Generator

**By Muhammad Muzammil**

A modern, feature-rich **Stylish Name Generator** built with HTML, CSS,
and JavaScript.\
It instantly generates **150+ Unicode-based stylish name designs**,
allows **one-click copying**, **copy all**, and **download as .txt** ---
all inside a clean, elegant UI.

------------------------------------------------------------------------

## 🚀 Features

### ✅ **Generate 150+ Stylish Name Variants**

-   Bold Unicode
-   Italic Unicode
-   Script / Fraktur / Bubble\
-   Small Caps\
-   Leet text\
-   Zalgo (glitch)\
-   Full-width\
-   Emoji-decorated styles\
-   Symbol surrounds\
-   Spaced variations\
-   Hybrid & random combinations

### ✅ **Copy Single or All Names**

### ✅ **Download Results as .txt**

### ✅ **Fully Browser-Based --- No Backend Needed**

------------------------------------------------------------------------

## 🛠️ Technologies Used

  Technology             Purpose
  ---------------------- -----------------------------------------
  **HTML5**              Structure
  **CSS3**               UI design (dark theme, responsive grid)
  **JavaScript (ES6)**   Logic + Unicode transformations
  **Clipboard API**      Copy functionality
  **Blob API**           TXT download

------------------------------------------------------------------------

## 📖 How It Works

1.  User enters a name\
2.  Clicks **Generate**\
3.  Script creates 150+ transformed variants\
4.  User can copy or download results

------------------------------------------------------------------------

## 🔠 Unicode Transformations

Includes:\
- Mathematical Bold\
- Mathematical Italic\
- Script\
- Fraktur\
- Mono-space\
- Bubble letters\
- Small caps\
- Leet conversions\
- Zalgo effects\
- Spaced text\
- Emoji/symbol decorations
